The MIT license in [LICENSE](LICENSE) covers the SOFTWARE ONLY. This repository
bundles no collected data; each user queries the APIs with their own key.

  the query URL and access date.

  API is governed by the KIPRIS Plus terms of use (https://plus.kipris.or.kr).
  Check those terms before redistributing raw responses (`raw/kipris_page*.json`).
